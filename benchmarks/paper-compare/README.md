# Paired comparison against the paper's reference implementation

Three scripts that time this repository's pin-scale prover and verifier against
the paper's own prototype,
[georgeorourke/hachi-pcs](https://github.com/georgeorourke/hachi-pcs) at
`6d90cac`, on the same machine and at the same size (ℓ = 30, i.e. `BLOCKS = 1024`).
Like the Rayon harness next door, this sits entirely outside the optimization
loop: nothing here is read by `make run-bench`, the accept rule or
`make ledger-check`.

| Script | What it does |
|---|---|
| `bench_ours.sh` | `make run-profile BLOCKS=…` N times; averages Commit, Prove (excl. commit), its sumcheck share and the rest, and the verifier's core check |
| `bench_reference.sh` | clones and pins `hachi-pcs`, generates its `2^L`-coefficient witness file once, builds it (optionally the nightly AVX-512 arm), runs it N times and averages the same five rows from its `time-graph` spans |
| `bench_interleaved.sh` | alternates the two, one pair at a time and in alternating order, so laptop drift (thermals, power profile) lands inside each pair instead of between the two sides; writes per-pair ratios to `paired.csv` |

```bash
benchmarks/paper-compare/bench_interleaved.sh                 # 10 pairs at the paper's scale, ~3.3 h
N=3 BLOCKS=64 L=26 benchmarks/paper-compare/bench_interleaved.sh  # smoke test
benchmarks/paper-compare/bench_ours.sh --summarize DIR        # re-summarize an earlier run
```

The header of each script lists every environment variable it reads. `BLOCKS`
and `L` must describe the same problem (`L = 20 + log2 BLOCKS`); the interleaved
script refuses a mismatched pair before doing any work.

**Local state, never committed.** `work/` holds the reference clone and its
witness file (4 GiB at ℓ = 30, regenerated by `--prepare` when missing), and
`results/` holds every run's logs and CSVs. Both are in `.gitignore`: a timing is
a statement about one machine at one moment. The reference needs ~14 GiB of RAM
at ℓ = 30. Run on mains power on an otherwise idle machine.

**Reading the numbers.** The reference's Prove/Verify cover a superset of this
crate's protocol layer (see [`logs/paper-impl/README.md`](../../logs/paper-impl/README.md)
§ Parameters), and `make run-profile`'s wall time includes untimed scaffolding
and a second verifier replay, which is why `bench_ours.sh` sums the timed phase
lines rather than reading the wall clock. Compare the paired ratios, not means
taken from different sessions.
